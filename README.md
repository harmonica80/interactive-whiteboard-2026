# 即時互動白板 - 課堂互動系統 (Interactive Whiteboard 2026)

一個專為現代教學設計的跨平台即時互動白板與課堂互動系統。支援多班級開課管理、向量白板手繪、即時提問、選擇題測驗、影片互動、即時文字雲、課堂氛圍回饋與全班即時廣播，為師生打造流暢、高度互動的智慧教學體驗。

## ✨ 核心功能特色

### 1. 🎨 即時互動白板繪圖
- **完整白板工具**：鋼筆、筆刷、螢光筆、橡皮擦（支援一鍵清除便利貼與筆跡）、幾何圖形、箭頭、便利貼與文字輸入。
- **可拖曳收合工具列**：電腦與行動裝置均支援浮動工具列拖曳位置與快速收合，最大化畫布視野。
- **行動裝置雙指縮放**：支援手機與平板兩指流暢手勢縮放與平移畫布。

### 2. 🏫 班級開課管理與專屬短網址
- **多班級開課代碼**：支援自訂班級代碼（如 301, ENG-A），防止未授權學生隨意占用資料庫空間。
- **專屬短網址與雙軌 QR Code**：
  - 自動整合多重短網址備援機制（is.gd ➜ v.gd ➜ TinyURL 代理），自動生成好記的精簡短網址。
  - 同步提供「原始長連結 QR Code」與「專屬短網址 QR Code」，支援一鍵投影大螢幕供全班掃描或複製。
  - 在後台「班級管理」頁面與右下角浮動選單均可隨時開啟分享面板。
- **跨班教材與題庫複製**：一鍵將特定班級的題庫、影片與教材複製至其他班級，自動過濾個別學生的個人作答記錄。
- **班級專屬學生頭像圖鑑**：支援 8×6 (48 格) 角色圖鑑上傳，內建 ChatGPT AI 透明背景頭像提示詞生成指南。

### 3. 📡 全班即時廣播系統
- 老師在提問區、圖片分享、影片分享、文字雲、互動白板、隨機抽人等功能頁面上方，均設有「📢 全班廣播」按鈕。
- 點擊後即可即時引導全體學生畫面同步切換至老師當前所在的教學模組。

### 4. 🧩 豐富多樣的課堂教學互動模組
- **💬 即時提問區**：學生即時發問、分組資料夾管理、即時點讚與提問置頂。
- **📝 隨堂測驗出題**：單選題、複選題、自訂詳解、答對/答錯音效反饋，支援即時統計圖表與成績匯出。
- **☁️ 互動文字雲**：學生字詞即時聚集、詞頻可視化、雙指手勢縮放、文字雲歷史記錄保留與跨班複製。
- **🎲 隨機抽人點名**：動畫轉盤隨機挑選學生，公平有趣。
- **🎬 影片隨堂測驗**：同步播放 YouTube 教學影片，支援特定時間點彈出隨堂互動題目。
- **😊 輕量浮動表情條**：自訂 16 款豐富課堂氛圍表情，支援星級評等與即時學習狀態回報。
- **📽️ 同步簡報系統**：投影片播放、手繪註記、行動裝置雙指手勢縮放、簡報 JSON 匯出與匯入。
- **⏱️ 課堂計時器與背景音樂**：提供經典翻頁、LED 數位、圓環風格，內建巴洛克與古典名曲背景音樂。

### 5. 🛡️ 教師身分防護與安全體系
- **SHA-256 加密安全**：教師專屬密碼多班級自動通用，免除記誦多組密碼的負擔。
- **7 天初始密碼寬限期**：新開課白板支援過渡預設密碼 `1234`（自首次登入啟用起算 7 天寬限期），方便新手教師首次進入後台自訂專屬密碼。
- **安全自救秒重設機制**：內建安全提示與安全提問（如：第一所任教學校），遺忘密碼時在登入頁即可秒自救重設，無需依賴外部信箱。
- **防暴力破解保護**：連續輸錯 5 次自動鎖定 3 分鐘，保障課堂資料安全。

## 🚀 快速開始

### 1. 取得專案並於本機開啟
直接使用現代瀏覽器開啟 `index.html` 即可使用。

或使用本地靜態伺服器：
```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js
npx serve
```

### 2. 免費建置專屬 Firebase 資料庫（3 分鐘完成）
1. 前往 [Firebase 主控台](https://console.firebase.google.com/)，點選「新增專案」。
2. 建立專案後，在左側選單選擇「資料庫和儲存空間」 ➔ 「**Realtime Database**」並建立資料庫（位置建議選擇 `新加坡 asia-southeast1`）。
3. 前往 Realtime Database 的「**規則 (Rules)**」頁籤，貼上 **100 年免維護安全防護規則**（有效至 2125 年）：
```json
{
  "rules": {
    "$node": {
      ".read": "now < 4891468800000",
      ".write": "now < 4891468800000"
    }
  }
}
```
4. 切換回「資料 (Data)」頁籤，複製頁面頂部的資料庫網址（以 `https://...` 開頭）。
5. 開啟白板網頁，點選右下角「💡 教室資訊與資源」 ➔ 「🛠️ 建立自己的白板」，貼上網址即可一鍵生成專屬連結與短網址 QR Code！

## 🛠️ 開發與驗證

本專案使用現代前端原生技術與 Node.js 開發環境，無需複雜的編譯封裝即可直接執行。

```bash

npm run dev

# 執行自動化測試 (包含 ES Module 語法檢查與 Playwright 白板畫布驗證)
npm test
```

## 💻 技術規格

- **前端核心**：HTML5 Canvas、CSS3、Vanilla JavaScript (ES6+)、tldraw 白板引擎
- **即時通訊與資料庫**：Firebase Realtime Database (WebSocket 即時雙向同頻)
- **短網址與 QR Code**：is.gd、v.gd、TinyURL Proxy 多層備援、QRCode.js
- **身分安全驗證**：Web Crypto API (SHA-256 原生加密)、自適應防爆破鎖定機制
- **跨平台支援**：桌面端（Chrome、Edge、Safari、Firefox）與行動端（iOS Safari、Android Chrome 平板與手機）
